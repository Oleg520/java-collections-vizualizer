# Стабильное рабочее пространство — Issue #59

Chromium / Playwright, production preview, DPR 1. Скриншоты сделаны с
`prefers-reduced-motion: reduce`, после завершения layout и измерения Dock.

| Состояние | Скриншот |
|---|---|
| 1440×900, дерево, sidebar и Dock раскрыты | [desktop-expanded](desktop-expanded.png) |
| 1440×900, sidebar свёрнут, Dock центрирован по расширенной визуализации | [sidebar collapsed](desktop-sidebar-collapsed.png) |
| 1440×900, семь полей, нижняя область увеличена, Dock свёрнут | [details expanded](desktop-details-expanded.png) |
| 1100×360, короткий viewport, доступные sidebar/footer и детали | [short desktop](desktop-short.png) |
| 412×839, Events/Details и раскрытый Dock | [mobile 412](mobile-412.png) |
| 320×740, детали, тонкий разделитель и свёрнутый Dock | [mobile 320](mobile-320.png) |
| 1440×900, старый и новый буферы ArrayList в одной области прокрутки | [ArrayList copy](arraylist-copy.png) |

При 1440×900 панель визуализации — 576 px; sidebar — 824 px под header 76 px.
Инспектор занимает всю высоту центральной колонки с необходимым запасом под Dock,
до штатного отступа main (16 px) от низа страницы. При свернутом Dock запас меньше;
во время навигации по шагам он не меняется. Нет отдельной пустой полосы под инспектором.
На коротких экранах документ прокручивается, области не обрезаются высотой окна.
При экстремальной высоте desktop-окна до 320 px sidebar возвращается в поток
документа, поскольку закреплённым областям не хватает места для полезного списка.
Последние сценарии и информационный низ доступны прокруткой (проверено при 1100×240).

Видимая полоса разделителя — половина области захвата; убрана дополнительная
верхняя граница Technical Details, верхний отступ текста уменьшен с 17 до 8 px.
Клавиши: ↑/↓ — 5%, Shift+↑/↓ — 10%, Home/End — границы 15/85% верхней области.
Значение сохраняется при переключении вкладок и trace в текущей вкладке браузера;
перезагрузка страницы возвращает исходные 55/45. Sidebar также раскрыт по умолчанию.

Проверки используют настоящий Java API. Автоматизированные случаи находятся в
`frontend/e2e/workspace.spec.ts` и `playback-dock.spec.ts`. Выполнен просмотр реального
рендера desktop/mobile и короткого экрана, включая последние элементы областей.
Touch проверен эмуляцией Chromium, физические устройства и screen reader не проверены.
Новых инструментов diagram navigation, breadcrumbs selector и изменений истории нет.
